Hash#

lib/crypto/Hash.kop · 8 fungsi

SHA-256, SHA-1, dan HMAC-SHA256 murni Kopi untuk integritas, JWT, PBKDF2, dan TLS.

import Hash;
import Cipher;

System.out.println(Cipher.hexenc(Hash.sha256(Net.bytes("abc"))));
