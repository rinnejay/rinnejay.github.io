Semua pustaka ditulis dalam bahasa Kopi (lib/*.kop) di atas builtin Net dan tipe dasar. Import selalu eksplisit:

import Str;
import Math;
import HttpServer;

Referensi API lengkap (signature semua fungsi diekstrak langsung dari source): Referensi pustaka → Core · Net · Crypto. Halaman di bawah ini adalah turunan berisi modul yang paling sering dipakai dengan pola pemakaian.

1. Str — teks & konversi#

String dan int[] byte kompatibel; hampir semua fungsi Str menerima keduanya.

copy(s) cat(a,b) slice(s,from,n) at(s,i) salin, gabung, potong, indeks

replaceByte(from,to) replaceSeq(old,new) ganti byte / substring

padLeft(Str.fromInt(7), 3, 48) → "007".

3. Math, Digits, Stats, Matrix#

  • Math (80+ fungsi): abs sign min max clamp diff sumTo avgFloor, bit (isEven popcount highestBit bitLength isPowerOfTwo nextPow2 reverseBits), pangkat/akar/log (pow mod addMod mulMod powMod sqrt cbrt log2 log10), FPB/modular (gcd lcm isCoprime extendedGcd modInverse), prima (isPrime nextPrime primesUpTo primeCount nthPrime factorize eulerPhi), kombinatorika (factorial binomial permutation catalan fib lucas), geometri (distanceSq manhattan rectArea isRightTriangle).
  • Digits: reverse digitSum digitCount pow10 digitProduct isPalindrome isArmstrong digitalRoot printBase.
  • Stats: sum product min max range mean median mode variance stddev countEven countOdd.
  • Matrix (int[] datar, persegi): zero identity add sub scale mul transpose trace det det1 det2 det3 isIdentity.

Semua fungsi integer membungkus 32-bit; untuk matematika besar pakai long/Big.

5. Koleksi#

  • Map (int→int, open addressing): make(cap) put get getOr has remove clear size grow forEach(f).
  • MapStr (String→int, kapasitas+pool tetap): make(cap,poolCap) put get getOr has remove clear size used keyAtSlot valAtSlot.
  • Set (di atas Map): make add has remove size clear grow forEach.
  • Deque: make(cap) pushBack pushFront popFront popBack get size capacity isEmpty isFull clear.

Map/Set bisa tumbuh via grow; MapStr tidak (cocok untuk header).

6. File, Path, Time#

import File; import Path; import Time;

int fd = File.openRead("data.txt");
int n = File.size(fd);
int[] buf = new int[n];
File.readInto(fd, buf);
File.close(fd);

int out = File.create("hasil.txt");
File.writeAll(out, Net.bytes("halo\n"));
File.close(out);

System.out.println(Time.format(Time.epoch()));
System.out.println(Time.sleepMs(10));
Modul Fungsi

Path join base dir ext isAbsolute sep SEP
Time epoch monoMs sleepMs civil weekday format (UTC)

File.readInto membaca sampai buffer penuh/EOF. Untuk file besar, baca per blok.

8. Jaringan#

Tcp#

int fd = Tcp.open(Tcp.loopback(), 8080);   // -errno bila gagal
Tcp.sendBuf(fd, req);
int n = Tcp.recvAll(fd, buf);              // sampai EOF/buffer penuh
Tcp.shutdown(fd, 1);                       // 0=RD 1=WR 2=RDWR
Tcp.drop(fd);

Tcp.ip(a,b,c,d), Tcp.loopback(), Tcp.num(v), Tcp.cat/indexOf/tail.

Udp#

int s = Udp.open();
Udp.bind(s, 0, 9000);
Udp.sendTo(s, ip, port, Net.bytes("hi"));   // maks 1200 byte/datagram
int n = Udp.recvFrom(s, buf, from);         // from[0]=ip, from[1]=port

Dns / Resolv#

  • Dns.lookup(addr, port, nama, hasil, cap) — DNS over TCP ke server eksplisit.
  • Resolv.servers() — baca /etc/resolv.conf (fallback 8.8.8.8).
  • Resolv.lookupUdp(server, port, nama, timeoutMs, hasil, cap) — DNS UDP dengan timeout.
  • Resolv.lookup(nama, timeoutMs, hasil, cap) — coba semua server.

hasil[0] = RCODE, hasil[1..4] = oktet IPv4.

encode decode formEncode formDecode pair appendQuery hasScheme scheme authority host portOf path query fragment ip4 normalize resolve.

int[] u = Url.resolve("http://a/b/c/d;p?q", "../g");  // http://a/b/g

HttpServer, Static, Mime#

HttpServer: readRequest method path target version headerValue contentLength body bodyAny queryValue urlDecode statusText response responseKA respond responseFor headOnly send keepAlive cookie setCookie methodIs.

Static.serve(path) / serveKA(path,keep) menyajikan file + MIME dan menolak ... Mime.of(path) untuk Content-Type.

WebSocket#

accept(key) isUpgrade(req) handshake(req) frame(op,payload) text binary ping pong close(code) decode(buf,n) payload(f) opcode(f).

Tls (klien TLS 1.3)#

handshake(ip, port, pinSpki, randSes) → context; writeApp(ctx,data), readApp(ctx). pinSpki = SHA-256 DER SPKI leaf (TOFU). Belum ada TLS server dan belum verifikasi ECDSA CertificateVerify.

10. Auth & session#

import Pbkdf2; import Jwt; import Session; import Auth; import MapStr;

int[] hash = Pbkdf2.sha256(pass, salt, 100000, 32);
int[] token = Jwt.sign(payloadJson, secret);
int valid = Jwt.verify(token, secret, out);      // 1 sah, 0 salah, -1 bentuk

int[] ids  = MapStr.make(256, 8192);
int[] exps = MapStr.make(256, 8192);
int[] sid  = Session.create(ids, exps, uid, 3600);
int uid2   = Session.get(ids, exps, sid, Net.time());

int[] h = HttpServer.headerValue(req, Net.bytes("Authorization"));
Auth.checkBasic(h, Net.bytes("budi"), Net.bytes("rahasia"));
Auth.bearer(h);
