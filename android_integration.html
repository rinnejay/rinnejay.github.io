Android Integration

Kopi di Android berjalan via libkopivm.so (JNI) + kopivm_android.c. Bytecode .kbc sama dengan desktop — portable 100%.

Arsitektur

libkopivm.so
Shared library ARM64, eksport kopivm_android_load_mem, kopivm_android_run, dll.
JNI Wrapper
Java/Kotlin class KopiVM load library, pass bytecode, call run() tiap frame.
AAssetManager
Builtin Net.assetOpen/Read/Size baca langsung dari APK assets.
EGL/GLES/Vulkan
Net.glInit/vkInit terima ANativeWindow* dari SurfaceView.

Build libkopivm.so

sh
cd ~/kopi
make android-arm64
# Output: vm-android/libkopivm.so

# Copy ke Android project
cp vm-android/libkopivm.so android/app/src/main/jniLibs/arm64-v8a/

JNI API (C)

c
#include "kopivm.h"

// Load bytecode dari memory (asset)
int kopivm_android_load_mem(const void* data, size_t len);

// Load dari file internal storage
int kopivm_android_load_file(const char* path);

// Jalankan satu frame / sampai selesai
long kopivm_android_run(void);

// Heap usage (slots)
long kopivm_android_heap_used(void);

// Thread count (main + workers)
int kopivm_android_thread_count(void);

Kotlin/Java Wrapper

kotlin
package com.kopi.vm

class KopiVM {
    companion object {
        @JvmStatic
        external fun loadMem(data: ByteArray): Int
        @JvmStatic
        external fun loadFile(path: String): Int
        @JvmStatic
        external fun run(): Long
        @JvmStatic
        external fun heapUsed(): Long
        @JvmStatic
        external fun threadCount(): Int
    }

    init {
        System.loadLibrary("kopivm")
    }
}

// Usage di MainActivity
class MainActivity : AppCompatActivity() {
    private lateinit var kopiVM: KopiVM
    private lateinit var surfaceView: SurfaceView

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)

        // Load bytecode dari assets
        val kbc = assets.open("game.kbc").readBytes()
        KopiVM.loadMem(kbc)

        // Setup SurfaceView untuk GL
        surfaceView = SurfaceView(this).apply {
            holder.addCallback(object : SurfaceHolder.Callback {
                override fun surfaceCreated(holder: SurfaceHolder) {
                    // surface.handle = ANativeWindow_fromSurface
                    // pass ke kopivm via JNI extension
                }
            })
            setZOrderOnTop(true)
        }
        setContentView(surfaceView)
    }

    override fun onResume() {
        super.onResume()
        // Game loop
        Thread {
            while (!Thread.interrupted()) {
                KopiVM.run()
                Thread.sleep(16)  // ~60 FPS
            }
        }.start()
    }
}

Asset Loading

Bytecode .kbc + aset (texture, model, audio) diletakkan di app/src/main/assets/.

text
assets/
├── game.kbc              # bytecode utama
├── world_manifest.json   # streaming manifest
├── tex/
│   ├── desgreengrass.png
│   └── ...
└── kpak/
    ├── ganghous01_lax.kpak
    ├── lae2_roads07.kpak
    └── ...

Di Kopi, baca asset via builtin:

kopi
int fd = Net.assetOpen("tex/desgreengrass.png");
if (fd >= 0) {
    long size = Net.assetSize("tex/desgreengrass.png");
    int[] buf = new int[(size + 3) / 4];
    Net.assetRead(fd, buf, buf.length * 4);
    int tex = Net.glCreateTexture(w, h, 0, buf);
    Net.assetClose(fd);
}

Performance Tips

  • Gunakan malloc{} untuk alokasi besar (arena virtual 4 TB, fisik on-demand)
  • Minimalkan JNI call — batch di sisi Kopi
  • Texture atlas: pack multiple textures, bind once per frame
  • Frustum culling + distance culling di Renderer3D (built-in)
  • MSAA via RenderConfig.samples = 4 (GlesSubmit)
