<h2>kopicc — Compiler Kopi</h2>
<p><code>kopicc</code> menerjemahkan <code>.kop</code> ke assembly native (aarch64/x86-64) atau bytecode VM (KOP1).</p>

<h3>Usage</h3>
<div class="code-block">
  <div class="code-header"><span class="code-lang">sh</span><button class="code-copy"><svg width="14" height="14" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2"><rect x="9" y="9" width="13" height="13" rx="2"/><path d="M5 15H4a2 2 0 0 1-2-2V4a2 2 0 0 1 2-2h9a2 2 0 0 1 2 2v1"/></svg><span>Salin</span></button></div>
  <pre><code>kopicc [options] <file.kop>... -t <target> -o <output>

Targets:
  -t a64    # aarch64 assembly (.s) -> cc -> binary (ARM/Termux)
  -t x64    # x86-64 assembly (.s) -> cc -> binary (PC Linux/macOS)
  -t vm     # KOP1 bytecode (.kbc) -> kopivm

Options:
  -o <file>      # output file (required)
  -I <dir>       # tambah include path (default: lib/ di samping kopicc)
  --version      # versi compiler
  --help         # bantuan</code></pre>
</div>

<h3>Include Path & KOPPATH</h3>
<p>Default include path: folder <code>lib/</code> yang berada di direktori yang sama dengan binary <code>kopicc</code>.</p>
<div class="code-block">
  <div class="code-header"><span class="code-lang">sh</span><button class="code-copy"><svg width="14" height="14" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2"><rect x="9" y="9" width="13" height="13" rx="2"/><path d="M5 15H4a2 2 0 0 1-2-2V4a2 2 0 0 1 2-2h9a2 2 0 0 1 2 2v1"/></svg><span>Salin</span></button></div>
  <pre><code># Override dengan environment variable
KOPPATH=/custom/lib ./kopicc Main.kop -t vm -o out.kbc

# Atau -I per path
./kopicc -I /custom/lib -I ./local_lib Main.kop -t vm -o out.kbc</code></pre>
</div>

<h3>Bytecode Format KOP1</h3>
<p>Header <code>KOP1</code> (4 byte) + version (2 byte) + constant pool + method table + bytecode.</p>

<h3>JIT Compilation (aarch64)</h3>
<p>VM mengkompilasi hot path ke native ARM64 runtime (<code>jit_a64.inc</code>).</p>
<div class="code-block">
  <div class="code-header"><span class="code-lang">sh</span><button class="code-copy"><svg width="14" height="14" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2"><rect x="9" y="9" width="13" height="13" rx="2"/><path d="M5 15H4a2 2 0 0 1-2-2V4a2 2 0 0 1 2-2h9a2 2 0 0 1 2 2v1"/></svg><span>Salin</span></button></div>
  <pre><code># Disable JIT untuk debugging
KOPI_NOJIT=1 ./kopivm game.kbc

# JIT diaktifkan default di aarch64 (Termux, RPi 4+, Apple Silicon via Rosetta)</code></pre>
</div>

<h3>Build Android (libkopivm.so)</h3>
<p>Kopi menyediakan <code>kopivm-android-host</code> untuk build library shared Android:</p>
<div class="code-block">
  <div class="code-header"><span class="code-lang">sh</span><button class="code-copy"><svg width="14" height="14" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2"><rect x="9" y="9" width="13" height="13" rx="2"/><path d="M5 15H4a2 2 0 0 1-2-2V4a2 2 0 0 1 2-2h9a2 2 0 0 1 2 2v1"/></svg><span>Salin</span></button></div>
  <pre><code>cd ~/kopi
# Build libkopivm.so untuk arm64-v8a
make android-arm64
# Output: vm-android/libkopivm.so

# Integrasi Gradle (Android Studio)
# copy libkopivm.so ke app/src/main/jniLibs/arm64-v8a/
# load via System.loadLibrary("kopivm")</code></pre>
</div>
