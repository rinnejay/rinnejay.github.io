<h2>Android Integration</h2>
<p>Kopi di Android berjalan via <code>libkopivm.so</code> (JNI) + <code>kopivm_android.c</code>. Bytecode <code>.kbc</code> sama dengan desktop — portable 100%.</p>

<h3>Arsitektur</h3>
<div class="card-grid">
  <div class="card">
    <div class="card-title">libkopivm.so</div>
    <div class="card-desc">Shared library ARM64, eksport <code>kopivm_android_load_mem</code>, <code>kopivm_android_run</code>, dll.</div>
  </div>
  <div class="card">
    <div class="card-title">JNI Wrapper</div>
    <div class="card-desc">Java/Kotlin class <code>KopiVM</code> load library, pass bytecode, call run() tiap frame.</div>
  </div>
  <div class="card">
    <div class="card-title">AAssetManager</div>
    <div class="card-desc">Builtin <code>Net.assetOpen/Read/Size</code> baca langsung dari APK assets.</div>
  </div>
  <div class="card">
    <div class="card-title">EGL/GLES/Vulkan</div>
    <div class="card-desc"><code>Net.glInit/vkInit</code> terima <code>ANativeWindow*</code> dari <code>SurfaceView</code>.</div>
  </div>
</div>

  <div class="code-header"><span class="code-lang">kotlin</span><button class="code-copy"><svg width="14" height="14" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2"><rect x="9" y="9" width="13" height="13" rx="2"/><path d="M5 15H4a2 2 0 0 1-2-2V4a2 2 0 0 1 2-2h9a2 2 0 0 1 2 2v1"/></svg><span>Salin</span></button></div>
  <pre><code>package com.kopi.vm

class KopiVM {
    companion object {
        @JvmStatic
        external fun loadMem(data: ByteArray): Int
        @JvmStatic
        external fun loadFile(path: String): Int
        @JvmStatic
        external fun run(): Long
        @JvmStatic
        external fun heapUsed(): Long
        @JvmStatic
        external fun threadCount(): Int
    }

    init {
        System.loadLibrary("kopivm")
    }
}

// Usage di MainActivity
class MainActivity : AppCompatActivity() {
    private lateinit var kopiVM: KopiVM
    private lateinit var surfaceView: SurfaceView

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)

        // Load bytecode dari assets
        val kbc = assets.open("game.kbc").readBytes()
        KopiVM.loadMem(kbc)

        // Setup SurfaceView untuk GL
        surfaceView = SurfaceView(this).apply {
            holder.addCallback(object : SurfaceHolder.Callback {
                override fun surfaceCreated(holder: SurfaceHolder) {
                    // surface.handle = ANativeWindow_fromSurface
                    // pass ke kopivm via JNI extension
                }
            })
            setZOrderOnTop(true)
        }
        setContentView(surfaceView)
    }

    override fun onResume() {
        super.onResume()
        // Game loop
        Thread {
            while (!Thread.interrupted()) {
                KopiVM.run()
                Thread.sleep(16)  // ~60 FPS
            }
        }.start()
    }
}</code></pre>
</div>

<h3>Performance Tips</h3>
<ul>
  <li>Gunakan <code>malloc{}</code> untuk alokasi besar (arena virtual 4 TB, fisik on-demand)</li>
  <li>Minimalkan JNI call — batch di sisi Kopi</li>
  <li>Texture atlas: pack multiple textures, bind once per frame</li>
  <li>Frustum culling + distance culling di <code>Renderer3D</code> (built-in)</li>
  <li>MSAA via <code>RenderConfig.samples = 4</code> (GlesSubmit)</li>
</ul>
