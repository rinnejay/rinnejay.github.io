<h2>kopivm — Virtual Machine KOP1</h2>
<p>Interpreter register-based untuk bytecode KOP1 v1. Mendukung JIT aarch64, builtin <code>Net.*</code> (socket, GL, audio, thread, channel, asset), dan GC arena-based.</p>

<h3>Architecture</h3>
<div class="card-grid">
  <div class="card">
    <div class="card-title">Register-based Interpreter</div>
    <div class="card-desc">Operand stack + local slots per frame. Instruksi 1-byte opcode + operand inline.</div>
  </div>
  <div class="card">
    <div class="card-title">Per-thread State</div>
    <div class="card-desc">Setiap thread (main + threadspawn) punya VState sendiri: stack, frames, locals, heap arena.</div>
  </div>
  <div class="card">
    <div class="card-title">Arena Allocator</div>
    <div class="card-desc">Bump-pointer arena per thread (32 MB default). <code>malloc{}</code> = mmap 4 TB virtual (MAP_NORESERVE).</div>
  </div>
  <div class="card">
    <div class="card-title">JIT aarch64</div>
    <div class="card-desc">Hot loop detection -> compile ke native ARM64. <code>KOPI_NOJIT=1</code> untuk disable.</div>
  </div>
</div>

<h3>Builtin Net.* Dispatch Table</h3>
<p>Opcode <code>OP_NET (33)</code> dengan index <code>bi</code> (0-145). Lihat <a href="bahasa_kopi.html#builtin-net-system-calls">Bahasa Kopi</a> untuk daftar lengkap.</p>

<h3>Thread Model</h3>
<ul>
  <li>Thread utama: ID 1, <code>VState</code> statis di <code>run()</code></li>
  <li><code>Net.threadspawn(() => { ... })</code> -> spawn pthread, <code>VState</code> baru per thread</li>
  <li>Heap arena thread <strong>tidak dibebaskan</strong> saat thread selesai (objek bisa dibagikan)</li>
  <li><code>threadjoin</code> = <code>pthread_join</code> + sinkronisasi memori</li>
  <li>Maks 8192 thread bersamaan (slot handle)</li>
</ul>

<h3>Channel CSP</h3>
<ul>
  <li>Buffer melingkar + condvar (<code>pthread_cond_t</code>)</li>
  <li>Payload <code>long</code> (64-bit) — gunakan untuk pointer/handle</li>
  <li>Varian <code>fn</code> untuk closure executor pattern</li>
  <li><code>chanclose</code> membangunkan semua penunggu</li>
</ul>

<h3>Memory & GC</h3>
<ul>
  <li>Global arena: 32 MB (<code>HEAPLEN = 1<<22</code> slots)</li>
  <li><code>malloc<N> { ... }</code> — arena eksplisit N bytes</li>
  <li><code>malloc { ... }</code> — arena otomatis 4 TB virtual (MAP_NORESERVE)</li>
  <li>Thread heap didaftarkan ke registry global untuk cross-thread ref safety</li>
  <li>Tidak ada GC tracing — arena-based, manual scope via <code>malloc</code></li>
</ul>
