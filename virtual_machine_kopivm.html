Virtual Machine (kopivm)

1.54 Panduan Stable

kopivm — Virtual Machine KOP1

Interpreter register-based untuk bytecode KOP1 v1. Mendukung JIT aarch64, builtin Net.* (socket, GL, audio, thread, channel, asset), dan GC arena-based.

Usage

sh
kopivm  [args...]

# Environment variables
KOPISIM=1           # enable PPM snapshot (frame 3, 15, 30, 45)
MAXFRAME=60         # max frame untuk KOPISIM
KOPI_NOJIT=1        # disable JIT (debug)

Architecture

Register-based Interpreter
Operand stack + local slots per frame. Instruksi 1-byte opcode + operand inline.
Per-thread State
Setiap thread (main + threadspawn) punya VState sendiri: stack, frames, locals, heap arena.
Arena Allocator
Bump-pointer arena per thread (32 MB default). malloc{} = mmap 4 TB virtual (MAP_NORESERVE).
JIT aarch64
Hot loop detection -> compile ke native ARM64. KOPI_NOJIT=1 untuk disable.

Builtin Net.* Dispatch Table

Opcode OP_NET (33) dengan index bi (0-145). Lihat Bahasa Kopi untuk daftar lengkap.

Thread Model

  • Thread utama: ID 1, VState statis di run()
  • Net.threadspawn(() => { ... }) -> spawn pthread, VState baru per thread
  • Heap arena thread tidak dibebaskan saat thread selesai (objek bisa dibagikan)
  • threadjoin = pthread_join + sinkronisasi memori
  • Maks 8192 thread bersamaan (slot handle)

Channel CSP

  • Buffer melingkar + condvar (pthread_cond_t)
  • Payload long (64-bit) — gunakan untuk pointer/handle
  • Varian fn untuk closure executor pattern
  • chanclose membangunkan semua penunggu

Graphics Pipeline (Net.gl* / Net.vk*)

Backend GPU native di VM — tidak butuh Java/JNI. Dua backend:

kopi
int r = Net.glInit(surface, 1280, 720);  // surface = ANativeWindow* (Android) atau 0
if (r != 1) die("GL init failed");

Net.glSetViewport(0, 0, 1280, 720);

// Shader (packed string array: tiap char = 1 slot)
int prog = Net.glCreateProgram(vert_src, frag_src);

// Buffer
int vbuf = Net.glCreateBuffer(1, vertex_count * 8, vertex_data);  // kind=1 vertex
int ibuf = Net.glCreateIndexBuffer(index_count, index_data);

// Texture
int tex = Net.glCreateTexture(w, h, 0, rgba_data);  // fmt=0 RGBA8

// Draw loop
Net.glClear(0x8CA8C0FF);
Net.glBindTexture(tex);
Net.glDrawIndexed(prog, vbuf, ibuf, index_count, 1, 0, 0, 0);
Net.glPresent();
kopi
int r = Net.vkInit(surface, 1280, 720);
int pipeline = Net.vkCreatePipeline(vert_spv, frag_spv, layout);
int vbuf = Net.vkCreateBuffer(1, count, vertex_data);
int ibuf = Net.vkCreateIndexBuffer(count, index_data);
int tex = Net.vkCreateTexture(w, h, 0, rgba_data);

Net.vkSetViewport(0, 0, 1280, 720);
Net.vkClear(0x8CA8C0FF);
Net.vkDrawIndexed(pipeline, vbuf, ibuf, count, 1, 0, 0, 0);
Net.vkPresent();

Audio (Net.audio*)

kopi
Net.audioInit(1);  // 1 = OpenAL

int buf = Net.audioCreateBuffer(2, 44100, pcm_data);  // stereo
int src = Net.audioPlay(buf, 1.0f, 1.0f, 0);  // vol, pitch, loop
Net.audioSetListener(0,0,0,  0,0,-1);       // pos, forward
Net.audioSetSourcePos(src, 5, 0, 0);        // pos sumber
Net.audioStop(src);
Net.audioShutdown();

Input Injection

kopi
// Touch (action: 0=down, 1=move, 2=up)
Net.injectTouch(0, 0, 100.0f, 200.0f, timestamp_ms);

// Key
Net.injectKey(keycode, action);  // action: 0=down, 1=up

// Gamepad
Net.injectGamepad(device_id, button, value);  // value: 0.0..1.0 atau -1.0..1.0

Memory & GC

  • Global arena: 32 MB (HEAPLEN = 1<<22 slots)
  • malloc { ... } — arena eksplisit N bytes
  • malloc { ... } — arena otomatis 4 TB virtual (MAP_NORESERVE)
  • Thread heap didaftarkan ke registry global untuk cross-thread ref safety
  • Tidak ada GC tracing — arena-based, manual scope via malloc

Android Integration (libkopivm.so)

API JNI di kopivm_android.c:

c
// Load bytecode dari memory (asset)
kopivm_android_load_mem(kbc_data, kbc_len);

// Atau dari file
kopivm_android_load_file("/data/data/pkg/files/game.kbc");

// Run frame (dipanggil tiap frame dari Java/JNI)
long ret = kopivm_android_run();

// Stats
long heap_used = kopivm_android_heap_used();
int thread_count = kopivm_android_thread_count();
