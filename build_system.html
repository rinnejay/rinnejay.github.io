1.54 Panduan Beta

Build System

Kopi menggunakan Makefile sederhana tanpa dependensi eksternal selain cc (clang/gcc), make, dan python3 (untuk test/docs).

Targets Utama

sh
make            # build kopicc + kopivm (default)
make test       # jalankan test suite (butuh python3)
make clean      # hapus build artifacts
make android-arm64  # build libkopivm.so untuk Android
make docs       # generate dokumentasi (script ini)

Struktur Build

kopi/
├── src/                    # Compiler (kopicc)
│   ├── *.c, *.inc, *.h
│   └── Makefile.inc
├── vm/                     # VM (kopivm)
│   ├── *.c, *.inc
│   └── Makefile.inc
├── lib/                    # Standard library (.kop)
├── android/                # Android project (Gradle + JNI)
├── examples/               # Contoh program
├── tests/                  # Test suite
├── tools/                  # Build tools (gen_docs.py, check_docs.py)
├── kopicc                  # Compiler binary (output)
├── kopivm                  # VM binary (output)
└── Makefile                # Entry point

Compiler Flags

kopicc dikompilasi dengan:

makefile
CFLAGS = -O2 -std=c11 -Wall -Wextra -Wno-unused-parameter
                   -D_GNU_SOURCE -D_POSIX_C_SOURCE=200809L
                   -I./src -I./vm
LDFLAGS = -lm -lpthread -ldl

VM Flags

makefile
VM_CFLAGS = -O2 -std=c11 -Wall -Wextra
                 -D_GNU_SOURCE -D_POSIX_C_SOURCE=200809L
                 -I./src -I./vm
VM_LDFLAGS = -lm -lpthread -ldl -lEGL -lGLESv2 -lOpenSLES -lOpenAL
             # Android: -landroid -llog -lEGL -lGLESv2 -lOpenSLES

Android Build

Gradle project di android/ dengan JNI wrapper kopivm_android.c.

sh
cd android
./gradlew assembleDebug
# Output: app/build/outputs/apk/debug/app-debug.apk

# Atau build libkopivm.so manual
cd ~/kopi
make android-arm64
# Output: vm-android/libkopivm.so

Cross-compile x86-64 di ARM

sh
# Check syntax x64 assembly tanpa run
./kopicc hello.kop -t x64 -o hello64.s
cc -target x86_64-linux-gnu -c hello64.s -o /dev/null

# Full cross-compile (butuh toolchain x86_64-linux-gnu)
cc -target x86_64-linux-gnu hello64.s -o hello64

Continuous Integration

GitHub Actions workflow (contoh):

yaml
name: CI
on: [push, pull_request]
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Install deps
        run: sudo apt-get update && sudo apt-get install -y clang make python3
      - name: Build
        run: make
      - name: Test
        run: make test
      - name: Build Android
        run: make android-arm64
