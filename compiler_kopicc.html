Compiler (kopicc)

1.54 Panduan Stable

kopicc — Compiler Kopi

kopicc menerjemahkan .kop ke assembly native (aarch64/x86-64) atau bytecode VM (KOP1).

Usage

sh
kopicc [options] ... -t  -o 

Targets:
  -t a64    # aarch64 assembly (.s) -> cc -> binary (ARM/Termux)
  -t x64    # x86-64 assembly (.s) -> cc -> binary (PC Linux/macOS)
  -t vm     # KOP1 bytecode (.kbc) -> kopivm

Options:
  -o       # output file (required)
  -I        # tambah include path (default: lib/ di samping kopicc)
  --version      # versi compiler
  --help         # bantuan

Contoh Kompilasi

sh
# Development / testing
./kopicc Main.kop World.kop Player.kop -t vm -o game.kbc
./kopivm game.kbc

# Dengan KOPISIM untuk snapshot PPM
KOPISIM=1 MAXFRAME=60 ./kopivm game.kbc
# generates build/sim1.ppm, sim2.ppm, ...
sh
# Release ARM64 (Termux, RPi, ARM server)
./kopicc Main.kop -t a64 -o app.s
cc app.s -o app -O2
./app
sh
# Release x86-64 (PC Linux/macOS)
./kopicc Main.kop -t x64 -o app64.s
cc app64.s -o app64 -O2
./app64

# Syntax check only (tanpa link)
cc -target x86_64-linux-gnu -c app64.s -o /dev/null
sh
# Semua .kop di folder src/
./kopicc src/*.kop -t vm -o build/game.kbc

# Atau list manual (lebih cepat untuk project besar)
./kopicc src/Main.kop src/World.kop src/Player.kop \
         lib/game/render/3d/Renderer3D.kop lib/game/math/Mat4.kop \
         -t vm -o build/game.kbc

Include Path & KOPPATH

Default include path: folder lib/ yang berada di direktori yang sama dengan binary kopicc.

sh
# Override dengan environment variable
KOPPATH=/custom/lib ./kopicc Main.kop -t vm -o out.kbc

# Atau -I per path
./kopicc -I /custom/lib -I ./local_lib Main.kop -t vm -o out.kbc

Output Files

TargetExtensionDescription
-t vm.kbcKOP1 bytecode (portable, jalankan via kopivm)
-t a64.sARM64 assembly (GAS syntax), assemble dengan cc
-t x64.sx86-64 assembly (GAS/NASM), assemble dengan cc

Bytecode Format KOP1

Header KOP1 (4 byte) + version (2 byte) + constant pool + method table + bytecode.

JIT Compilation (aarch64)

VM mengkompilasi hot path ke native ARM64 runtime (jit_a64.inc).

sh
# Disable JIT untuk debugging
KOPI_NOJIT=1 ./kopivm game.kbc

# JIT diaktifkan default di aarch64 (Termux, RPi 4+, Apple Silicon via Rosetta)

Build Android (libkopivm.so)

Kopi menyediakan kopivm-android-host untuk build library shared Android:

sh
cd ~/kopi
# Build libkopivm.so untuk arm64-v8a
make android-arm64
# Output: vm-android/libkopivm.so

# Integrasi Gradle (Android Studio)
# copy libkopivm.so ke app/src/main/jniLibs/arm64-v8a/
# load via System.loadLibrary("kopivm")

Error Messages

Error format: file.kop:line:col: message. Contoh:

sh
Main.kop:42:15: tipe tidak dikenal
    42 |     World worldRef;
       |               ^
  saran: Periksa ejaan nama dan tipe operand.
Forward reference: Class harus didefinisikan sebelum dipakai, atau gunakan file terpisah + import. Method call pada field butuh variabel lokal dulu: ObjModel m = this.cj; m.recomputeBounds();
