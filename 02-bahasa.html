Dokumen ini adalah referensi sintaks dan semantik yang berlaku di v1.20. Semua contoh bisa dikompilasi ke a64 dan VM (kecuali ditandai).

1. Bentuk program#

class Main {
    public static void main(String[] args) {
        System.out.println("halo");
    }
}
  • main boleh static void main() atau static void main(String[] args).
  • Anggota class bisa statis (namespace) atau instance (field + method this, sejak v1.12) — lihat bagian 12.
  • Tidak ada package, inheritance, interface, enum, atau generics; lihat 06 — Batas.

2. Komentar#

// komentar satu baris
/* komentar
   beberapa baris */

Literal angka dibaca compile-time dengan pemeriksaan rentang; overflow aritmetika membungkus (wrap), bukan error. Pembagian integer memotong ke arah nol; % mengikuti tanda kiri (seperti Java).

Cast & promosi#

long l = 7;
int i = (int)l;               // eksplisit, boleh kehilangan presisi
double f = i;                 // pelebaran implisit
int balik = (int)3.99;        // 3 (truncation)

Campuran signed/unsigned memakai aturan promosi eksplisit di ast.h (mis. int + uint32 → long). Bila ragu, pakai cast eksplisit.

4. Variabel & scope#

int x = 1;
int y = 2, z = 3;             // multi-deklarasi
x += 4;                       // compound: += -= *= /= %= &= |= ^= <<= >>= >>>=
x++;                          // hanya sebagai statement, bukan ekspresi
  • Variabel lokal wajib diinisialisasi (int x; ditolak).
  • Scope per blok { }; if/for/while punya scope sendiri.
  • Nama variabel tidak boleh dideklarasikan dua kali dalam satu scope.

5. Operator#

Kelompok Operator

Perbandingan < <= > >= == !=
Logika && || ! (short-circuit)

Cabang ternary harus bertipe sama, atau sama-sama String/int[]. Kondisi harus boolean.

6. Kontrol alir#

if (x > 0) { ... } else if (x == 0) { ... } else { ... }

while (kondisi) { ... }

do {
    ...
} while (kondisi);            // badan minimal sekali; break/continue OK

for (int i = 0; i < 10; i++) { ... }
for (;;) { break; }           // init/kondisi/update boleh kosong

break keluar dari loop terdekat; continue lanjut ke iterasi berikut.

switch (v1.19)#

switch (x) {
    case 1: System.out.println("satu");
    case 2: System.out.println("dua");
    default: System.out.println("lain");
}

Aturan:

  • Tanpa fall-through: badan tiap case adalah blok sendiri — setelah badan selesai, eksekusi keluar dari switch (tidak jalan ke case berikut).
  • case hanya menerima literal bilangan bulat (boleh negatif, mis. case -3:); default opsional dan boleh di posisi mana pun.
  • Selector dievaluasi sekali (disimpan ke variabel temp compiler).
  • break/continue di dalam badan case tetap milik loop terluar (switch adalah rantai if/else, bukan blok loop) — di luar loop, break tidak valid.
  • Deklarasi di badan case hanya terlihat di case itu (scope per case).
  • Selector bertipe int-ish (int/byte/short); long/String ditolak (butuh cast / bandingkan dengan if).
  • Duplikat case atau duplikat default ditolak compiler; maksimum 64 case.

switch murni gula parser — bytecode & mesin native tidak berubah.

Belum ada try/catch, throw, atau assert.

7. Array#

int[] a = new int[10];        // selalu di-zero-kan (termasuk setelah memReset)
a[0] = 7;
for (int i = 0; i < a.length; i++) a[i] = i * i;

int[] b = a;                  // alias, bukan salinan
int[] c = Str.copy(a);        // salinan (byte-array helper)
  • Indeks di luar 0..length-1 menghentikan program dengan pesan array tidak valid (indeks/ukuran salah).
  • Array bisa diparamkan/dikembalikan; ukuran tetap setelah dibuat.

Array bertipe (v1.16) — elemen 64-bit, fisik sama dengan int[]:

long[] x = new long[4];       // elemen long 64-bit penuh
x[1] = 123456789012345L;      // tanpa terpangkas 32-bit

String[] s = new String[3];   // elemen String
s[0] = "kopi";
System.out.println(s[0]);     // mencetak teks elemen
System.out.println(s.length);
  • String[] args di main kini tipe sungguhan (String[]); isi parameter tidak dibaca (program berdiri sendiri).
  • Identitas referensi berlaku juga untuk long[]/String[]: String[] t = s; t == s → 1 (alias, bukan salinan).
  • Tidak ada konversi implisit antar tipe array: int[] x = new long[2] ditolak, begitu juga melempar long[] ke parameter int[].
  • Metode fungsional (forEach, map, ...) masih khusus int[]; untuk long[]/String[] tulis loop for biasa.
  • Belum ada array literal ({1,2,3}) atau array multi-dimensi.

Metode fungsional array (gula)#

int[] a = new int[5];
for (int i = 0; i < a.length; i++) a[i] = i + 1;

static void cetak(int x) { System.out.println(x); }
...
a.forEach(x => cetak(x));
int[] b = a.map(x => x * 2);
int[] g = a.filter(x => x % 2 == 0);
int s = a.reduce(0, (acc, x) => acc + x);
boolean ada = a.any(x => x > 4);
int idx = a.findIndex(x => x == 3);

Daftar: forEach forEachIndexed map filter reduce any all countWhere findIndex sumBy copy reverse.

8. String#

String adalah tipe teks native (v1.17: opaque — tidak lagi sama dengan int[]); literal "..." dan '...' adalah String (bukan char).

v1.18: representasi packed — byte tersimpan rapat 1 byte per karakter (8 byte per slot 64-bit, little-endian): "Kopi" memakai 8+8 = 16 byte arena, bukan 40. Konversi int[] ↔ String tetap eksplisit dan tetap satu-satunya cara berpindah representasi; compiler menyisipkannya otomatis di batas (deklarasi, assignment, return, argumen) sehingga kode sumber tidak berubah.

String s = "Kopi";
System.out.println(s.length);       // 4 (byte)
System.out.println(s[0]);           // 75 ('K')
System.out.println(s + " Bahasa");  // konkatenasi String+String
System.out.println(s == "Kopi");    // perbandingan isi

+ untuk String hanya dengan String; untuk angka gunakan Str.fromInt atau template.

Interop String ↔ byte buffer kini eksplisit (v1.17, tetap di v1.18):

int[] buf = Net.strbytes(s);   // teks → salinan byte
String t = Net.mkstr(buf);     // byte → teks baru (materialisasi)
  • String → int[] masih bebas (String adalah view byte, ala []byte(s) di Go).
  • int[] → String wajib Net.mkstr(...) — buffer byte tidak lagi otomatis dianggap teks; int[] w = u; (u String) ditolak compiler.
  • Fungsi pembangun teks (Str.trim, Str.upper, Str.fromInt, Str.fromLong, Str.fromDouble, Str.boolText, Str.repeat, Str.padLeft, Str.splitAt, ...) kini mengembalikan String. Str.substring bernama Str.sub (kembalikan String); Str.slice tetap int[] untuk buffer I/O.
  • println(int[]) tetap mencetak buffer byte sebagai teks (debug).

Metode instance (butuh import Str;)#

import Str;

String t = "  Kopi Bahasa  ";
t.trim()                 // "Kopi Bahasa"
t.upper()                // "KOPI BAHASA"
t.lower()
t.trim().substring(0, 4) // "Kopi"
"arena".charAt(2)        // 101
"game server".indexOf("server")   // 5
"game server".indexOf("x")        // -1
"kopi".contains("op")    // true
"kopi".startsWith("ko")
"kopi".endsWith("pi")
"kopi".equals("kopi")
"Kopi".equalsIgnoreCase("kOPI")
"".isEmpty()
"ab".repeat(3)           // "ababab"
"123".toInt()            // 123
"a,b".replaceSeq(",", ";")
"7".padLeft(3, 48)       // "007"
"teks".countByte(101)
"é".utf8Count()

Metode ini hanya gula parser menjadi Str.<nama>(receiver, ...). Bila Str belum diimpor, compiler memberi pesan: metode String 'x' butuh 'import Str;'.

Template string (backtick)#

import Str;

int umur = 20;
String nama = "budi";
System.out.println(`Halo {nama}, umur {umur}, tahun depan {umur + 1}`);
System.out.println(`nested {`inner {umur}`}`);
System.out.println(`literal {{x}} \{y\}`);
  • {ekspresi} boleh ekspresi apa pun (panggilan metode, aritmetika, template bersarang).
  • Angka/boolean memakai Str.fromInt/fromLong/fromDouble/boolText, jadi import Str; wajib bila ada interpolasi non-String.
  • Escape: \n, \t, \r, \\, \{, \} (backtick di-escape dengan backslash + backtick); {{/}} = kurung literal.
  • Hanya backtick yang memformat; "..."/'...' tetap literal.

9. Fungsi#

class Main {
    static int tambah(int a, int b) { return a + b; }

    static void sapa(String nama) {
        System.out.println("Halo " + nama);
    }

    static int faktorial(int n) {
        if (n <= 1) return 1;
        return n * faktorial(n - 1);
    }

    public static void main(String[] args) {
        System.out.println(tambah(40, 2));
        sapa("budi");
        System.out.println(faktorial(6));
    }
}
  • Maksimum 8 parameter (batas backend native).
  • Tidak ada overloading: dua metode dengan nama sama (di seluruh unit compile) ditolak, meskipun beda parameter.
  • Rekursi didukung. return tanpa nilai hanya untuk void.
  • public/private diterima tetapi belum menegakkan akses.

10. Lambda & fn#

class Main {
    static int terapkan(fn f, int x) { return f(x); }

    public static void main(String[] args) {
        int faktor = 3;
        fn kali = x => x * faktor;                 // ekspresi
        fn tambah = (a, b) => {                    // blok
            int r = a + b;
            return r;
        };
        System.out.println(kali(10));              // 30
        System.out.println(terapkan(kali, 7));     // 21
        System.out.println(tambah(40, 2));         // 42
    }
}
  • Bentuk: x => ekspresi, (a, b) => { ... }, () => ....
  • Tipe parameter/return pada fn dinamis adalah int (v1).
  • Capture snapshot by value saat lambda dibuat; mutasi di dalam lambda tidak bocor keluar.
  • Lambda bisa menjadi argumen fn dan dipanggil sebagai f(...); maksimum 5 argumen saat pemanggilan dinamis.

11. Class sebagai namespace#

class Keranjang {
    static int total(int harga, int jumlah) { return harga * jumlah; }
    static int diskon(int total) {
        if (total >= 100000) return total * 9 / 10;
        return total;
    }
}

class Main {
    public static void main(String[] args) {
        System.out.println(Keranjang.diskon(Keranjang.total(25000, 5)));
    }
}

Semua class dalam satu build berbagi namespace. Simpan helper di file sendiri lalu import Keranjang;.

12. Class instance#

Sejak v1.12 sebuah class bisa punya field dan method instance (metode tanpa static). Sejak v1.14 field juga bisa long, String, dan bertipe class. Sejak v1.15 ada constructor — metode yang namanya sama dengan class, dipanggil lewat new. this merujuk objek yang sedang berjalan:

class Titik {
    int x;
    int y;
    long besar;          // field 64-bit (v1.14)
    String nama;         // field referensi (v1.14)

    Titik(int ax, int ay, String nm) {   // constructor (v1.15)
        this.x = ax;
        this.y = ay;
        this.nama = nm;
        this.besar = (long)(ax * 1000000);
    }

    long luasBesar() {
        return this.besar * (this.x + this.y);
    }
}

class Kotak {
    int w;
    Titik pojok;         // field bertipe class (v1.14)

    Kotak(int w0, int x0, int y0, String nm) {
        this.w = w0;
        this.pojok = new Titik(x0, y0, nm);   // constructor di dalam constructor
    }
}

class Main {
    public static void main(String[] args) {
        Titik a = new Titik(10, 20, "alpha");     // lewat constructor
        System.out.println(a.luasBesar());        // long utuh
        System.out.println(a.nama == "alpha");    // isi String (Str.equals)

        Kotak k = new Kotak(5, 2, 3, "pojok");
        System.out.println(k.pojok.x);            // rantai field: 2
        System.out.println(k.pojok.nama == "pojok");

        Titik alias = k.pojok;                    // referensi yang sama
        alias.x = 99;
        System.out.println(k.pojok.x);            // 99 — identitas
        System.out.println(alias == k.pojok);     // 1
    }
}

Aturan yang berlaku:

  • Deklarasi bertipe class: Titik t = new Titik();, parameter boolean sama(Titik o), return static Titik buat(), dan field bertipe class (Titik pojok;) — semua didukung. Class harus didefinisikan sebelum dirujuk sebagai tipe.
  • Constructor (v1.15): nama metode = nama class, tidak boleh static, satu per class (tanpa overload). new K(args) mengalokasi objek (semua field di-zero) lalu menjalankan badan constructor; return; di tengah badan boleh, return nilai; tidak. Class tanpa constructor tetap bisa new K() (semua field 0).
  • Field selalu di-zero saat new (referensi menunjuk null; deref null = error runtime dengan stack trace di VM).
  • p == q membandingkan referensi (identitas), bukan isi — sama seperti Java. Untuk isi: a.nama == "alpha" membandingkan isi String, dan method pembanding untuk objek.
  • Penugasan field dicek nama class: k.pojok = new Kotak() ke field bertipe Titik ditolak dengan pesan jelas.
  • Metode tanpa static = metode instance. main wajib static.

Batas v1.15 (dirancang jujur):

  • Field double/float belum didukung (butuh jalur register float di ketiga backend); field lain: 32-bit (int/boolean/byte/short) dan 64-bit (long/String/tipe class).
  • Tidak ada overload constructor (satu per class) dan tidak ada this(...) pemanggil constructor lain.
  • Dispatch statis (tanpa inheritance/interface/vtable); Titik secara internal adalah tape 64-bit ber-ukuran jumlah field.
  • Receiver method harus variabel atau field: b.kuadran() ok, k.pojok.kuadran() ok (v1.15), new Titik(1,2).x belum — simpan dulu ke variabel. Rantai field (k.pojok.x, baca & tulis) didukung.
  • Objek bisa dipakai di lambda (ditangkap by-value seperti variabel lain).

13. JSON literal#

import Json;

class Main {
    public static void main(String[] args) {
        int[] u = json {"nama": "budi", "umur": 20, "aktif": true};
        System.out.println(Json.write(u));
        System.out.println(Json.asInt(Json.get(u, "umur")));   // 20
        int[] a = json [1, 2, 3];
        System.out.println(Json.count(a));
    }
}
  • Literal json { ... } / json [ ... ] adalah tape int[] yang bisa disimpan, diparamkan, dan diubah dengan Json.put/del/add (immutable).
  • Maksimum 8 entri per literal; untuk lebih banyak susun bertahap.
  • Json.parse untuk teks JSON dari luar; Json.write untuk serialisasi.

14. Memori: malloc { ... }, arena 32 MB, tanpa GC#

Semua alokasi dinamis (array, string hasil operasi) masuk arena bump allocator 32 MB. Tidak ada free per objek. Sejak v1.20 compiler mengurus pembebasan secara otomatis lewat blok malloc:

malloc {
    int[] sementara = new int[10000];   // hidup selama blok
    String tmp = Str.upper(text);
    // ... pakai ...
}                                      // arena blok dibebaskan OTOMATIS

Compiler menyisipkan penanda arena saat masuk blok dan mengembalikan arena ke penanda itu di semua jalur keluar:

  • akhir blok,
  • break / continue yang keluar dari blok (milik loop di luar blok),
  • return dari dalam blok.

Contoh aman di loop panas tanpa memanggil reset manual:

for (int i = 0; i < 1000000; i++) {
    malloc {
        int[] buf = new int[100000];   // 800 KB, dibebaskan tiap iterasi
        proses(buf);
    }
}

Aturan keamanan#

Rujukan (String, array, objek) tidak boleh keluar dari blok — isinya dibebaskan di akhir blok. Compiler menolaknya saat kompilasi:

String luar;
malloc { luar = Str.upper("x"); }        // ditolak: rujukan keluar blok
malloc { return Str.upper("x"); }        // ditolak: return rujukan
malloc { hasilArr[0] = "x"; }            // ditolak: String ke array luar
malloc { obj.nama = "x"; }               // ditolak: String ke field luar

Yang boleh (dan lazim): menulis nilai (int/long/bool/double) ke variabel/array/field luar, serta membaca rujukan luar di dalam blok:

int[] hasil = new int[4];
malloc {
    int[] tmp = new int[16];
    tmp[0] = luar.length;    // baca String luar: boleh
    hasil[0] = tmp[0];       // tulis NILAI ke array luar: boleh
}

Bila butuh rujukan hasil, salin keluar lewat nilai (mis. panjang, isi byte) atau alokasikan hasilnya di luar blok.

memMark / memReset manual (opsional)#

Masih tersedia untuk kendali halus (mis. reset per request di server yang membangun struktur jangka panjang):

int mark = Net.memMark();
int[] sementara = new int[10000];
// ... pakai ...
Net.memReset(mark);       // buang semua alokasi SETELAH mark
  1. Alokasikan data yang harus hidup sebelum memMark.
  2. memReset(mark) membebaskan semua alokasi setelah mark — jangan menyimpan pointer hasil alokasi setelah mark lalu memakainya lagi.
  3. new int[n] selalu men-zero-kan elemen, termasuk memori daur ulang.
  4. Tanpa reset, program batch panjang bisa kehabisan arena; malloc{} atau reset per request/iterasi menghindarinya.
  5. Lebih dari 32 MB → kopi: arena memori habis + exit 1 (bukan crash).

Catatan jujur: malloc{} adalah region scope, bukan GC. Rujukan yang diselundupkan lewat jalur yang tak terlihat compiler (mis. method lain menyimpan parameter ke variabel global) tetap tanggung jawab programmer; pola itu belum dijaga pemeriksa.

15. Keluar & kode status#

Net.exit(0);      // keluar seketika; tidak ada finally/atexit

Net.exit memakai syscall exit langsung sehingga buffer stdio tidak di-flush. Selesaikan output (mis. println) sebelum memanggilnya.

Error runtime: nomor baris + stack trace#

Saat program VM menabrak error runtime — pembagian dengan nol, indeks array di luar batas, arena penuh, dsb. — kopivm mencetak pesan dengan baris sumber dan stack trace lalu keluar dengan kode status 1:

kopivm: error: indeks array di luar batas (5)
  stack trace (terdalam dulu):
    at luar (utama.kop:9)
    at main (utama.kop:13)
  • Informasi baris membawa ongkos 3–5 byte per statement di bytecode dan tidak menambah operasi host (hanya menyimpan nomor baris).
  • Nama file di-intern ke cpool; byte tambahan umumnya sekali per metode.
  • Backend native (a64/x64) saat ini tetap mencetak pesan singkat tanpa trace — ini fitur VM (lihat roadmap: trap berline untuk native).
  • Error saat kompilasi (kopicc) selalu sudah berline sejak awal.
