# rinnejay.github.io — dokumentasi Kopi

Situs GitHub Pages untuk bahasa **Kopi** (☕).

- Live: https://rinnejay.github.io/
- Sumber dokumentasi (Markdown + generator): https://github.com/rinnejay/kopiLanguage/tree/main/docs
- Lisensi: MIT

Halaman HTML di repo ini **dihasilkan otomatis** oleh
`tools/md2html.py` dari repo `kopiLanguage`. Jangan menyunting `.html`
langsung; ubah `.md` di repo sumber lalu jalankan:

```sh
make docs
```

lalu salin `docs/*.html`, `docs/style.css`, `docs/.nojekyll` ke root repo
ini (atau gunakan skrip deploy).
