Tipe Array

Array adalah reference type dengan header panjang. Sintaks deklarasi:

kopi
int[] a = new int[10];       // 10 elemen, init 0
int[] b = new int[] {1, 2, 3};  // literal array
float[] c = new float[5] {1.0f}; // parsial: sisa 0.0f
String[] d = new String[3];     // null elements
Array bounds checked: Akses a[i] dengan i < 0 atau i >= a.length → runtime panic.

Packed Array (1 byte/elemen)

Untuk buffer byte/uint8 efisien memori (v1.43+):

kopi
byte[] buf = new byte[1024];      // 1 byte per elemen
uint8[] u8 = new uint8[512];      // alias byte[]
buf[0] = 255;                     // 0..255

Packed array cocok untuk I/O jaringan, texture, audio buffer. Konversi dari String: Net.strbytes(str).

Class & Object

kopi
class Player {
    // Instance fields
    String nama;
    int hp;
    float x, y;
    
    // Static field (konstanta)
    static int MAX_HP = 100;
    
    // Constructor
    Player(String n) {
        this.nama = n;
        this.hp = MAX_HP;
    }
    
    // Instance method
    void takeDamage(int dmg) {
        this.hp = this.hp - dmg;
        if (this.hp < 0) this.hp = 0;
    }
    
    // Static method
    static Player create(String n) {
        return new Player(n);
    }
}

// Usage
Player p = Player.create("CJ");
p.takeDamage(10);

Visibility

Semua member public (tidak ada private/protected). Field instance default 0/null/false.

Inheritance

Tidak ada inheritance class. Komposisi via field + interface-like pattern (struct dengan method).

Control Flow

kopi
// if-else
if (x > 0) {
    System.out.println("positif");
} else if (x < 0) {
    System.out.println("negatif");
} else {
    System.out.println("nol");
}

// while
int i = 0;
while (i < 10) {
    if (i == 5) { i = i + 1; continue; }
    System.out.println(i);
    i = i + 1;
}

// for (C-style)
for (int i = 0; i < 10; i = i + 1) {
    System.out.println(i);
}

// switch (integer/string)
switch (cmd) {
    case "start": start(); break;
    case "stop": stop(); break;
    default: unknown();
}

// ternary
int max = (a > b) ? a : b;

Functions & Closures

kopi
// Static method
static int add(int a, int b) { return a + b; }

// Lambda (fn) — bisa capture variabel lokal
fn adder = (int x) => x + 1;
int r = adder(5);  // 6

// Multi-statement lambda
fn worker = (int id) => {
    System.out.println("Worker " + id + " start");
    Net.sleep(100);
    System.out.println("Worker " + id + " done");
    return id * 2;
};

// Closure capture
int base = 10;
fn addBase = (int x) => base + x;  // capture base
System.out.println(addBase(5));    // 15

Memory: malloc Block

Arena allocation eksplisit — semua alokasi di dalam blok dibebaskan sekaligus:

kopi
// Eksplisit capacity (bytes)
malloc<1024 * 1024> {
    int[] big = new int[100000];
    String s = "data " + big.length;
    // big & s dibebaskan otomatis di sini
}

// Otomatis (mmap 4096 MB, MAP_NORESERVE)
malloc{} {
    int[] huge = new int[50000000];  // ~200 MB virtual, fisik saat disentuh
    // dibebaskan di akhir blok
}
Arena bersarang: malloc bisa bersarang — arena dalam mewarisi kapasitas parent. Objek yang lolos ke luar arena (via return) akan dangling — jangan lakukan itu.

kopi
try {
    int fd = Net.openr("config.json");
    if (fd < 0) throw "file not found";
    // ...
} catch (String err) {
    System.out.println("Error: " + err);
} finally {
    // cleanup (opsional)
}
